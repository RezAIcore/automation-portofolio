## 🚀 Project 1: Google Form → Google Sheets → Notion Automation

### 📌 Problem
Banyak orang kesulitan mengatur data dari Google Form. Biasanya:
- Jawaban tersimpan di Google Sheets
- Tapi harus dipindahkan manual ke Notion
- Membuat data tercecer dan makan waktu

### 💡 Solution
Saya membuat **automation** yang otomatis memindahkan data dari:
1. Google Form → Google Sheets (default)
2. Google Sheets → Notion Database (pakai Make/Zapier)

### ✅ Result
- Hemat waktu input manual  
- Semua data tersinkron di Notion  
- Bisa dipakai untuk **freelancer, mahasiswa, atau UMKM**  

### 🛠 Tools Used
- Google Forms  
- Google Sheets  
- Notion  
- Make (Integromat) / Zapier
